# Projeto Inicial — Hello World

Projeto em etapa inicial de desenvolvimento, criado para registrar no GitHub a organização, as primeiras evidências de implementação e a aplicação de boas práticas de desenvolvimento com Inteligência Artificial.

## Objetivo desta etapa

Demonstrar que o desenvolvimento foi iniciado de forma organizada, versionada e documentada.

## Estrutura

```text
.
├── ATIVIDADE_INICIAL.md
├── README.md
├── index.html
└── docs/
    ├── BOAS_PRATICAS_IA.md
    └── DIARIO_DESENVOLVIMENTO.md
```

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Verifique a página inicial do projeto.

## Uso de Inteligência Artificial

A IA é utilizada como ferramenta de apoio para planejamento, revisão e desenvolvimento. Todo conteúdo sugerido é revisado e testado antes de ser incorporado ao projeto.

As decisões finais sobre o projeto são responsabilidade do desenvolvedor.
