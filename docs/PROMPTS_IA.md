# Registro de Prompts e Uso de IA

## Objetivo

Este arquivo registra os prompts utilizados como apoio ao desenvolvimento inicial do projeto, demonstrando aplicação consciente de Inteligência Artificial e boas práticas de desenvolvimento.

> Observação: os prompts abaixo representam os pedidos utilizados nesta etapa. Eles não substituem requisitos que eventualmente estejam em uma parte da atividade do professor que não foi fornecida.

## Prompt 1 — Planejamento inicial

**Prompt:**

> Analise os requisitos da atividade e monte uma estrutura inicial de projeto organizada, considerando que o objetivo desta etapa é demonstrar que o desenvolvimento foi iniciado e aplicar boas práticas de desenvolvimento com Inteligência Artificial.

**Uso:** planejamento da estrutura inicial do repositório.

**Revisão humana:** a estrutura foi conferida e adaptada para conter documentação, código inicial e registros do desenvolvimento.

## Prompt 2 — Boas práticas com IA

**Prompt:**

> Liste boas práticas para utilizar Inteligência Artificial no desenvolvimento de software, incluindo revisão humana, testes, segurança, organização e registro das alterações.

**Uso:** elaboração da documentação de boas práticas.

**Revisão humana:** as recomendações foram revisadas antes de serem registradas no projeto.

## Prompt 3 — Implementação inicial

**Prompt:**

> Crie uma implementação inicial simples para demonstrar que o desenvolvimento do projeto começou, mantendo o código organizado, compreensível e fácil de evoluir.

**Uso:** criação da primeira implementação funcional do projeto.

**Revisão humana:** o código foi analisado e mantido propositalmente simples, pois esta etapa avalia o início e a organização do desenvolvimento.

## Prompt 4 — Documentação

**Prompt:**

> Crie uma documentação inicial que apresente o objetivo do projeto, sua organização, como executar a implementação e quais são os próximos passos.

**Uso:** organização do README e da documentação inicial.

**Revisão humana:** as informações foram conferidas e alinhadas aos requisitos apresentados pelo professor.

## Prompt 5 — Registro da evolução

**Prompt:**

> Organize um diário de desenvolvimento para registrar as etapas realizadas, decisões tomadas, uso de IA, testes e próximos passos do projeto.

**Uso:** criação do registro de evolução do desenvolvimento.

**Revisão humana:** o conteúdo foi revisado para manter somente informações relacionadas à etapa inicial.

## Prompt 6 — Verificação dos requisitos

**Prompt:**

> Verifique se a estrutura inicial contém evidências de repositório acessível, início do desenvolvimento e aplicação de boas práticas com Inteligência Artificial. Aponte o que estiver faltando.

**Uso:** conferência final da etapa.

**Revisão humana:** a conferência foi utilizada para organizar os arquivos e deixar as evidências explícitas.

## Boas práticas adotadas

- Os prompts foram escritos de maneira objetiva.
- As respostas da IA foram revisadas antes do uso.
- A IA foi utilizada como ferramenta de apoio, não como substituta da decisão do desenvolvedor.
- O código foi mantido simples e compreensível.
- As alterações foram registradas no GitHub por meio de commits.
- Não foram incluídas senhas, tokens ou outras credenciais.
- Os requisitos conhecidos foram conferidos antes da finalização.

## Conclusão

O registro demonstra que a Inteligência Artificial foi utilizada de forma consciente durante a organização e o início do desenvolvimento do projeto, com revisão e decisão final do desenvolvedor.
