# Diário de Desenvolvimento — Etapa Inicial

## Registro 01 — Organização inicial

**Objetivo:** iniciar o desenvolvimento de forma organizada e deixar evidências verificáveis no GitHub.

**Ações realizadas:**

- revisão da finalidade da atividade;
- organização da documentação inicial;
- criação do README;
- criação da primeira implementação em HTML;
- registro das boas práticas de uso de IA;
- versionamento das alterações por commits.

**Resultado:** o repositório passou a conter documentação, uma primeira implementação executável e registros das práticas de desenvolvimento com IA.

## Decisões iniciais

- Utilizar GitHub como ferramenta de versionamento.
- Manter a documentação junto ao código.
- Fazer o desenvolvimento de maneira incremental.
- Revisar e testar as sugestões produzidas por IA antes de incorporá-las.
- Evitar informações sensíveis no repositório.
